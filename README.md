# Samuel Oluwatobi — Data Analytics Portfolio

Responsive static portfolio website built with HTML, CSS and JavaScript.

## Features
- Desktop and mobile responsive layout
- Subtle scroll-reveal animations
- Project filtering by platform and domain
- Fullscreen dashboard previews
- 15 dashboard projects
- LinkedIn, X and WhatsApp contact links
- No backend or paid hosting required

## Free GitHub Pages deployment
1. Create a public GitHub repository, e.g. `samuel-oluwatobi-portfolio`.
2. Upload the contents of this folder (not the parent folder itself).
3. In GitHub: Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. GitHub will provide the public `github.io` address.
